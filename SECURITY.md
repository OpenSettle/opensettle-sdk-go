# Security Policy

Please do not file public issues for security vulnerabilities.

Report security issues via:
- Email: OpenSettle@proton.me
- security.txt: https://opensettle.io/.well-known/security.txt

We acknowledge within 72 hours and provide a triage decision within 7 days.

Full disclosure policy: https://opensettle.io/legal/vulnerability-disclosure
Org-level policy: https://github.com/OpenSettle/.github/blob/main/SECURITY.md
